# 03. HTML-ийг JS-ээр өөрчлөх

## Зорилго

- JS-ээр HTML элементийг **сонгох**
- Элементийн текстийг **өөрчлөх**, **унших**

Энэ бол "Сонго → Сонс → Өөрчил" дүрмийн **Сонго** болон **Өөрчил** хэсэг.

## Элемент сонгох

CSS дээр элементийг class-аар нь `.name { }` гэж сонгодог. JS дээр яг адилхан сонгоно:

```html
<h1 class="name">???</h1>
```

```js
const nameText = document.querySelector(".name");
```

- `document` — HTML хуудас бүхэлдээ
- `querySelector(".name")` — хуудаснаас `name` class-тай элементийг хайж олно
- `const nameText` — олсон элементээ хувьсагчид хадгална

Цэгээ (`.`) мартаж болохгүй. Цэг нь "class" гэсэн утгатай, CSS-тэй яг адил.

## Текст өөрчлөх

```js
nameText.textContent = "Анужин";
```

`textContent` бол элементийн доторх текст. Шинэ утга өгөхөд хуудсан дээрх текст шууд солигдоно.

## Текст унших

```js
console.log(nameText.textContent);   // "Анужин"
```

## Хувьсагчтай хослуулах

```js
const age = 13;
ageText.textContent = `Нас: ${age}`;
```

HTML файл дотор текст бичээгүй ч JS өгөгдлөөсөө хуудсаа бөглөж чадна. Вэб сайтууд хэрэглэгчийн нэр, оноо, мэдээг ингэж харуулдаг.

## Түгээмэл алдаа

| Алдаа | Засвар |
|---|---|
| `querySelector("name")` | Цэг дутуу: `".name"` |
| `Cannot read properties of null` | Элемент олдоогүй. HTML дээрх class-ийн нэртэй үсэг үсгээр тулга |
| `nameText = "Анужин"` | `.textContent` дутуу: `nameText.textContent = "Анужин"` |
| `textcontent` | Том `C`-тэй: `textContent` |

## Даалгавар: Амьтны карт

`daalgavar/` хавтсанд `???` гэсэн тексттэй карт байгаа.

1. Гурван элементийг сонго.
2. Дуртай амьтныхаа мэдээллийг хувьсагчид хадгал.
3. Картын текстүүдийг хувьсагчаараа соль.
