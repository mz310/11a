# 05. CSS-ийг JS-ээр удирдах

## Зорилго

- JS-ээр элементэд CSS class **нэмэх, хасах, солих**
- HTML, CSS, JS гурвыг нэг дор ажиллуулах

Энэ хичээл бол гурван хэлийг холбох **гол хичээл**.

## Гол санаа

JS загварыг өөрөө зурдаггүй. CSS дээр загвараа **урьдчилж бэлдээд**, JS-ээр зөвхөн class-ийг нь асааж, унтраана.

```html
<!-- HTML: элемент -->
<div class="lamp"></div>
```

```css
/* CSS: хоёр төлөвийн загвар */
.lamp {
  background-color: #9ca3af;   /* унтраалттай: саарал */
}

.lamp-on {
  background-color: #facc15;   /* асаалттай: шар */
}
```

```js
// JS: class-ийг нэмж, хасна
lamp.classList.add("lamp-on");      // асаана
lamp.classList.remove("lamp-on");   // унтраана
```

`classList.add("lamp-on")` ажилласны дараа HTML дараах шиг болно:

```html
<div class="lamp lamp-on"></div>
```

Үүнийг F12 → **Elements** цонхноос нүдээрээ харж болно.

## Гурван команд

| Команд | Юу хийдэг вэ |
|---|---|
| `classList.add("x")` | `x` class нэмнэ |
| `classList.remove("x")` | `x` class хасна |
| `classList.toggle("x")` | Байвал хасна, байхгүй бол нэмнэ |

`classList` дотор class-ийн нэрийг **цэггүй** бичнэ. `querySelector` дотор цэгтэй, `classList` дотор цэггүй.

## style-аар шууд өөрчлөх

Ганц утгыг шууд өөрчилж бас болно:

```js
lamp.style.width = "200px";
lamp.style.backgroundColor = "red";
```

CSS дээр `background-color` гэж бичдэг бол JS дээр зураасгүй, `backgroundColor` гэж бичнэ.

Аль болох `classList` ашигла. Загвар CSS файлдаа, үйлдэл JS файлдаа байвал кодоо олоход амар. `style`-ийг тоогоор тооцож гаргасан утгад (жишээ нь өргөн нь оноотой тэнцүү байх) хэрэглэнэ.

## Түгээмэл алдаа

| Алдаа | Засвар |
|---|---|
| `classList.add(".lamp-on")` | Цэггүй: `"lamp-on"` |
| Class нэмэгдсэн ч өнгө солигдохгүй | CSS дээр `.lamp-on` нь `.lamp`-ийн **доор** бичигдсэн байх ёстой |
| `lamp.classlist` | Том `L`-тэй: `classList` |
| `style.background-color` | `style.backgroundColor` |

## Даалгавар: Өнгөт хайрцаг

`daalgavar/` хавтсанд нэг хайрцаг, дөрвөн товч байгаа. CSS дээр `.red`, `.blue`, `.round`, `.hidden` class бэлэн.

1. `Улаан` дарахад хайрцаг улаан болно.
2. `Цэнхэр` дарахад хайрцаг цэнхэр болно.
3. `Дугуй / Дөрвөлжин` дарахад хэлбэр нь солигдоно.
4. `Нуух / Харуулах` дарахад хайрцаг алга болж, дахин гарч ирнэ.
