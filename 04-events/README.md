# 04. Товч дарах

## Зорилго

- Хэрэглэгчийн үйлдлийг (товч дарах) JS-ээр **сонсох**
- "Сонго → Сонс → Өөрчил" дүрмийг бүтнээр нь хэрэглэх
- Тоолуур хийх

## Event гэж юу вэ?

Хэрэглэгчийн хийсэн үйлдэл бүрийг **event** (үзэгдэл) гэнэ: товч дарах, гараас үсэг бичих, хулгана хөдөлгөх. JS эдгээрийг "сонсож" байгаад, болох үед нь код ажиллуулна.

## addEventListener

```js
button.addEventListener("click", function () {
  // товч дарагдах БҮРД энэ хэсэг ажиллана
});
```

- `button` — сонсох элемент
- `"click"` — ямар үйлдлийг сонсох вэ
- `function () { ... }` — тэр үед ажиллах код. Функцийг 07-р хичээлд дэлгэрэнгүй үзнэ

## Гурван алхам

```js
// 1. СОНГО
const message = document.querySelector(".message");
const helloButton = document.querySelector(".hello-button");

// 2. СОНС
helloButton.addEventListener("click", function () {
  // 3. ӨӨРЧИЛ
  message.textContent = "Сайн уу!";
});
```

`{ }` доторх код хуудас нээгдэхэд **ажиллахгүй**. Зөвхөн товч дарагдах үед ажиллана.

## Тоолуур

```js
let count = 0;

plusButton.addEventListener("click", function () {
  count = count + 1;               // хуучин утган дээр 1 нэмээд буцааж хадгална
  countText.textContent = count;   // шинэ утгыг хуудсан дээр харуулна
});
```

Хоёр зүйлийг анзаар:

1. `count` өөрчлөгддөг тул `let` ашигласан.
2. Хувьсагчийг өөрчлөхөд хуудас **өөрөө шинэчлэгдэхгүй**. `textContent`-оор заавал харуулна.

## Нэг элемент олон class-тай байж болно

```html
<button class="button plus-button">+1</button>
```

- `button` — CSS загварт зориулсан, бүх товчинд ижил
- `plus-button` — JS-ээр яг энэ товчийг олоход зориулсан

## Түгээмэл алдаа

| Алдаа | Засвар |
|---|---|
| `"Click"` | Жижиг үсгээр: `"click"` |
| `addEventListener("click")` | Хоёр дахь хэсэг дутуу: `function () { ... }` |
| Тоо нэмэгдэхгүй, 1 дээр зогсоно | `let count = 0;` мөрийг `{ }`-ийн **гадна** бич |
| Төгсгөлд `});` дутуу | `{`-г `}`-ээр, `(`-г `)`-ээр хаана |

## Даалгавар: Оноо тоологч

`daalgavar/` хавтсанд гурван товч байгаа: `+1`, `-1`, `Тэглэх`.

1. Элементүүдээ сонго.
2. `+1` дарахад оноо нэгээр нэмэгдэнэ.
3. `-1` дарахад оноо нэгээр хасагдана.
4. `Тэглэх` дарахад оноо 0 болно.

## Өөрийгөө шалга

- `let count = 0;` мөрийг `{ }` дотор бичвэл юу болох вэ? Туршаад үз.
- "Сонго → Сонс → Өөрчил" гурван алхмыг өөрийнхөө үгээр тайлбарла.
