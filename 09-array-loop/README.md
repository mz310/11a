# 09. Массив ба давталт

## Зорилго

- Олон утгыг массивт хадгалах
- Давталтаар массивын утга бүр дээр ажиллах
- JS-ээр **шинэ HTML элемент үүсгэх**

## Массив

Хувьсагч нэг утга хадгалдаг бол массив **олон утгыг дарааллаар нь** хадгална.

```js
const fruits = ["Алим", "Банана", "Усан үзэм"];
```

Утга бүр дугаартай. Дугаар **0-ээс** эхэлнэ:

```js
fruits[0]        // "Алим"
fruits[1]        // "Банана"
fruits.length    // 3, нийт хэдэн утгатай вэ
```

Төгсгөлд нь шинэ утга нэмэх:

```js
fruits.push("Жүрж");
```

`const` массивт `push` хийж болно. Хайрцаг нь хэвээрээ, зөвхөн доторх зүйл нэмэгдэж байгаа.

## Давталт

Массивын утга бүр дээр ижил код ажиллуулна:

```js
for (const fruit of fruits) {
  console.log(fruit);
}
```

Уншихдаа: "`fruits` доторх `fruit` бүрийн хувьд `{ }` доторх кодыг ажиллуул". Массив 3 утгатай бол 3 удаа, 100 утгатай бол 100 удаа ажиллана.

Тоогоор давтах бас нэг хэлбэр бий:

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);   // 1, 2, 3, 4, 5
}
```

`i++` нь `i = i + 1` гэсэнтэй адил.

## Шинэ элемент үүсгэх

Одоо болтол HTML дээр бэлэн байсан элементийг өөрчилж байсан. JS **шинэ элемент** үүсгэж бас чадна:

```js
const item = document.createElement("li");   // 1. <li> үүсгэнэ
item.textContent = "Алим";                   // 2. текст өгнө
item.classList.add("fruit-item");            // 3. class өгнө
fruitList.append(item);                      // 4. хуудсан дээр байрлуулна
```

`append` хийх хүртэл элемент хуудсан дээр харагдахгүй.

## Массив + давталт + createElement

```js
function showFruits() {
  fruitList.innerHTML = "";   // хуучин жагсаалтыг цэвэрлэнэ

  for (const fruit of fruits) {
    const item = document.createElement("li");
    item.textContent = fruit;
    fruitList.append(item);
  }
}
```

HTML дээр `<li>` нэгийг ч бичээгүй. Массивт хэдэн утга байна, төдөн мөр үүснэ. Вэб сайтууд бараа, мэдээ, сэтгэгдлийн жагсаалтаа ингэж харуулдаг.

## Түгээмэл алдаа

| Алдаа | Засвар |
|---|---|
| Эхний утгыг `fruits[1]` гэж авах | Дугаар 0-ээс эхэлнэ: `fruits[0]` |
| `for (const fruit in fruits)` | `in` биш `of` |
| Элемент үүссэн ч харагдахгүй | `append` мартсан |
| Нэмэх бүрд жагсаалт давхардах | Давталтын өмнө `innerHTML = ""` хийж цэвэрлэ |

## Даалгавар: Дуртай кинонууд

`daalgavar/` хавтсанд хоосон жагсаалт, input, хоёр товч байгаа.

1. `movies` массив үүсгэж гурван киноны нэр хадгал.
2. `showMovies` функц бич. Массивын утга бүрийг `<li>` болгож харуулна, нийт тоог шинэчилнэ.
3. `Нэмэх` дарахад input-ийн утга массивт нэмэгдэнэ.
4. `Сүүлийнхийг устгах` дарахад массивын сүүлийн утга устана.
