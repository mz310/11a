# 10. Төгсгөлийн төсөл: Миний хийх зүйлс

Сурсан бүхнээ нэгтгэж, хийх ажлын жагсаалт (to-do list) хийнэ.

## Юу хийх вэ?

- Шинэ ажил бичээд `Нэмэх` дарахад жагсаалтад нэмэгдэнэ
- Ажлын нэр дээр дарахад "хийсэн" гэж зураастай болно, дахин дарахад буцна
- `Устгах` дарахад тухайн ажил устана
- Нийт хэдэн ажил байгааг харуулна
- Юу ч бичээгүй бол анхааруулга гарна
- `Харанхуй горим` товчоор хуудасны өнгийг солино

## Ямар мэдлэг хэрэглэх вэ?

| Хэсэг | Хичээл |
|---|---|
| Элементүүдээ сонгох | 03 |
| Товч дарахыг сонсох | 04 |
| `done`, `hidden`, `dark-mode` class солих | 05 |
| Input хоосон эсэхийг шалгах | 06, 08 |
| `addTask`, `updateCount` функц | 07 |
| Эхний ажлуудыг массиваас унших | 09 |
| Ажил бүрд `<li>` үүсгэх | 09 |

## Бэлэн байгаа зүйл

- `index.html` — хуудасны бүтэц бэлэн
- `style.css` — бүх загвар бэлэн. Дотор нь JS-ээр нэмж, хасах class-уудыг тэмдэглэсэн
- `script.js` — алхам алхмаар бичих `TODO`-тай

`index.html`, `style.css` хоёрыг эхлээд уншиж, ямар class байгааг тэмдэглэж ав.

## Алхмууд

`script.js` доторх `TODO`-г дарааллаар нь хий. Алхам бүрийн дараа хуудсаа шалга.

1. **Сонго.** Долоон элементийг сонгоно.
2. **Тоолуур.** `updateCount` функц нийт ажлын тоог харуулна.
3. **Ажил нэмэх.** `addTask` функц нэг ажлын `<li>`-г үүсгэж жагсаалтад нэмнэ. Хамгийн урт алхам, яарах хэрэггүй.
4. **Эхний ажлууд.** Массив дахь ажил бүрийг давталтаар нэмнэ.
5. **Нэмэх товч.** Input-ээс утга аваад `addTask`-ийг дуудна.
6. **Харанхуй горим.** `dark-mode` class-ийг сольж, товчны текстийг өөрчилнө.

## Ажил бүрийн бүтэц

`addTask("Ном унших")` дуудахад JS дараах HTML-ийг үүсгэнэ:

```html
<li class="task">
  <span class="task-text">Ном унших</span>
  <button class="delete-button">Устгах</button>
</li>
```

Нэг элементийг нөгөөгийн дотор хийхдээ `append` ашиглана:

```js
item.append(taskText);       // <span>-ийг <li> дотор хийнэ
item.append(deleteButton);   // <button>-ийг <li> дотор хийнэ
taskList.append(item);       // <li>-г <ul> дотор хийнэ
```

## Шинэ хоёр зүйл

```js
item.remove();              // элементийг хуудаснаас устгана
taskList.children.length    // <ul> дотор хэдэн <li> байгааг хэлнэ
```

## Нэмэлт сорилт

Үндсэн хэсгээ дуусгасан бол:

1. Хийсэн ажлын тоог тусад нь харуул: "Хийсэн: 2 / 5".
2. `Бүгдийг устгах` товч нэм.
3. Гараас `Enter` дарахад ажил нэмэгддэг болго. Сэжүүр: `"keydown"` event болон `event.key === "Enter"`.
4. Өөрийнхөөрөө загварыг нь өөрчил: өнгө, фонт, шинэ class.
