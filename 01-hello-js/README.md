# 01. Сайн уу, JavaScript

## Зорилго

- JavaScript юу хийдгийг ойлгох
- `script.js` файлыг `index.html`-тэй холбох
- Консол нээж, `console.log()` ашиглах

## JavaScript гэж юу вэ?

HTML хуудсанд юу байхыг, CSS ямар харагдахыг тодорхойлдог. JavaScript (товчоор JS) хуудсыг **хөдөлгөөнтэй** болгодог: товч дарахад юм болох, тоо бодох, текст солих гэх мэт.

## Файлуудаа холбох

```html
<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 class="title">Сайн уу</h1>

  <script src="script.js"></script>
</body>
```

- `<link>` нь CSS-ийг холбоно. `<head>` дотор бичнэ.
- `<script>` нь JS-ийг холбоно. `</body>`-ийн **яг өмнө** бичнэ.

Яагаад доор нь бичдэг вэ? Хөтөч HTML-ийг дээрээс доош уншдаг. JS ажиллах үед гарчиг, товч зэрэг элементүүд аль хэдийн үүссэн байх ёстой.

## Консол

Консол бол JS-тэй "ярилцдаг" цонх. Хэрэглэгч үүнийг хардаггүй, харин програмист кодоо шалгахдаа байнга ашигладаг.

- Windows: `F12` → **Console**
- Mac: `Cmd + Option + J`

## console.log()

Хаалтан доторх зүйлийг консол дээр хэвлэнэ.

```js
console.log("Сайн уу!");   // текстийг хашилтад бичнэ
console.log(2 + 3);        // тоог хашилтгүй бичнэ, хариу нь 5
```

## Тайлбар (comment)

`//`-ийн ард бичсэн зүйлийг хөтөч уншихгүй. Кодоо өөртөө болон бусдад тайлбарлахад хэрэглэнэ.

```js
// Энэ мөр ажиллахгүй, зөвхөн тайлбар
```

## Түгээмэл алдаа

| Алдаа | Засвар |
|---|---|
| `<script src="scripts.js">` | Файлын нэр яг таарах ёстой: `script.js` |
| `Console.log("сайн уу")` | Жижиг үсгээр: `console.log` |
| `console.log("сайн уу)` | Хашилтаа хаана: `"сайн уу"` |
| Консол дээр юу ч гарахгүй | Файлаа хадгалсан уу (Ctrl + S)? Хуудсаа дахин ачаалсан уу? |

## Даалгавар

`daalgavar/` хавтсыг нээ. Тэнд CSS, JS хоёр хоёулаа **холбогдоогүй** байгаа.

1. `index.html` дотор `style.css`-ийг холбо. Хуудас өнгөтэй болно.
2. `index.html` дотор `script.js`-ийг холбо.
3. `script.js` дотор нэрээ, дуртай хоолоо консол дээр хэвлэ.
4. Консолоор гурван бодлого бодуул.

## Өөрийгөө шалга

- `<script>` тагийг яагаад `</body>`-ийн өмнө бичдэг вэ?
- `console.log("5 + 5")` болон `console.log(5 + 5)` хоёрын ялгаа юу вэ?
