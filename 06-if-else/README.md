# 06. Нөхцөл

## Зорилго

- `if`, `else if`, `else` ашиглан шийдвэр гаргах
- Харьцуулах тэмдгүүдийг мэдэх
- Нөхцлөөс хамаарч текст, загварыг өөрчлөх

## Яагаад хэрэгтэй вэ?

Одоо болтол код маань үргэлж ижил зүйл хийдэг байсан. Нөхцөлтэй бол хуудас **нөхцөл байдлаас хамаарч өөр өөр** зүйл хийнэ: оноо 10 хүрвэл "Ялагч", 0-ээс доош бол хасахгүй гэх мэт.

## if / else

```js
if (score >= 10) {
  // нөхцөл ҮНЭН бол энэ хэсэг ажиллана
  statusText.textContent = "Ялагч!";
} else {
  // ХУДАЛ бол энэ хэсэг ажиллана
  statusText.textContent = "Үргэлжлүүл";
}
```

## else if

Хоёроос олон сонголттой үед:

```js
if (score >= 10) {
  statusText.textContent = "Ялагч!";
} else if (score >= 5) {
  statusText.textContent = "Сайн байна!";
} else {
  statusText.textContent = "Эхэлцгээе!";
}
```

Дээрээс доош шалгана. Эхний үнэн нөхцлийг олоод, үлдсэнийг нь алгасна.

## Харьцуулах тэмдэг

| Тэмдэг | Утга | Жишээ | Хариу |
|---|---|---|---|
| `>` | их | `7 > 5` | `true` |
| `<` | бага | `7 < 5` | `false` |
| `>=` | их буюу тэнцүү | `5 >= 5` | `true` |
| `<=` | бага буюу тэнцүү | `4 <= 5` | `true` |
| `===` | тэнцүү | `5 === 5` | `true` |
| `!==` | тэнцүү биш | `5 !== 3` | `true` |

Анхаар: `=` нь утга **хадгална**, `===` нь **харьцуулна**.

## Хоёр нөхцлийг холбох

| Тэмдэг | Утга | Хэзээ үнэн бэ |
|---|---|---|
| `&&` | ба | Хоёр нөхцөл **хоёулаа** үнэн үед |
| `\|\|` | эсвэл | Хоёр нөхцлийн **ядаж нэг** нь үнэн үед |

```js
if (score >= 5 && score < 10) {
  // оноо 5-аас 9-ийн хооронд байвал
}

if (firstName === "" || lastName === "") {
  // аль нэг нь хоосон байвал
}
```

## Class байгаа эсэхийг шалгах

```js
if (likeButton.classList.contains("liked")) {
  likeButton.textContent = "Таалагдсан";
} else {
  likeButton.textContent = "Таалагдлаа";
}
```

`contains` нь тухайн class байвал `true`, байхгүй бол `false` буцаана.

## Түгээмэл алдаа

| Алдаа | Засвар |
|---|---|
| `if (score = 10)` | Харьцуулахдаа `===` бич |
| `if score > 5 {` | Нөхцлөө хаалтанд бич: `if (score > 5) {` |
| `else (score < 5) {` | `else` нөхцөлгүй. Нөхцөлтэй бол `else if` |
| `=>` гэж бичих | Их буюу тэнцүү нь `>=` |

## Даалгавар: Батарей

`daalgavar/` хавтсанд батарей, `Цэнэглэх`, `Ашиглах` хоёр товч байгаа.

1. `Цэнэглэх` дарахад цэнэг 10-аар нэмэгдэнэ, гэхдээ 100-аас хэтрэхгүй.
2. `Ашиглах` дарахад цэнэг 10-аар буурна, гэхдээ 0-ээс доош орохгүй.
3. Цэнэгийн хувь болон баганын өргөн шинэчлэгдэнэ.
4. Өнгө нь цэнэгээс хамаарна: 20 ба түүнээс бага бол улаан, 60 ба түүнээс бага бол шар, бусад үед ногоон.

## Өөрийгөө шалга

- `=` болон `===` хоёрын ялгаа юу вэ?
- Жишээ код дээр `score >= 5` болон `score >= 10` хоёр нөхцлийн байрыг солибол юу болох вэ?
