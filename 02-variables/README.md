# 02. Хувьсагч

## Зорилго

- Хувьсагч гэж юу болохыг ойлгох
- `let`, `const` хоёрын ялгааг мэдэх
- Текст, тоо, boolean төрлийг таних
- Тоон үйлдэл хийх, текст нийлүүлэх

## Хувьсагч гэж юу вэ?

Хувьсагч бол **нэртэй хайрцаг**. Дотор нь утга хадгалаад, дараа нь нэрээр нь дуудаж ашиглана.

```js
let score = 0;
```

- `let` — "хайрцаг үүсгэ" гэсэн үг
- `score` — хайрцгийн нэр
- `=` — "дотор нь хий" гэсэн үг (тэнцүү гэсэн үг **биш**)
- `0` — хадгалах утга

## let ба const

```js
let score = 0;       // утгыг нь дараа өөрчилж болно
score = 10;          // болно

const city = "Улаанбаатар";   // утга нь өөрчлөгдөхгүй
city = "Дархан";              // АЛДАА
```

Дүрэм: эхлээд `const` гэж бич. Утгыг нь өөрчлөх хэрэг гарвал `let` болго.

## Өгөгдлийн төрөл

| Төрөл | Юу вэ | Жишээ |
|---|---|---|
| `string` | Текст. Хашилтад бичнэ | `"Сайн уу"` |
| `number` | Тоо. Хашилтгүй бичнэ | `12`, `3.5` |
| `boolean` | Үнэн эсвэл худал | `true`, `false` |

## Тоон үйлдэл

```js
const total = 5 + 3;      // 8
const left = 10 - 4;      // 6
const price = 3 * 500;    // 1500
const half = 10 / 2;      // 5
```

## Текст нийлүүлэх

```js
const studentName = "Тэмүүлэн";
const age = 12;

// 1-р арга: + тэмдгээр
const greeting = "Сайн уу, " + studentName + "!";

// 2-р арга: ` ` тэмдэг дотор ${ } ашиглана
const introduction = `Намайг ${studentName} гэдэг. Би ${age} настай.`;
```

`` ` `` тэмдэг нь гарын зүүн дээд буланд, `1`-ийн зүүн талд байдаг.

## Нэр өгөх дүрэм

- Англи үсгээр, утга учиртай нэр өг: `score`, `studentName`
- Хоёр үгтэй бол хоёр дахь үгийг том үсгээр эхлүүл: `favoriteFood`
- Тоогоор эхэлж болохгүй, хоосон зай авч болохгүй
- `name`, `top`, `status` гэсэн нэрийг хөтөч өөрөө ашигладаг тул `studentName`, `statusText` гэх мэтээр тодорхой бич

## Түгээмэл алдаа

| Алдаа | Засвар |
|---|---|
| `const age = "12";` | Тоог хашилтгүй бич: `12`. `"12"` бол текст |
| `let Score` гээд `score` гэж дуудах | Том, жижиг үсэг ялгаатай |
| `Assignment to constant variable` | `const`-ийг өөрчлөх гэсэн. `let` болго |
| `"Нас: ${age}"` | `${ }` зөвхөн `` ` ` `` дотор ажиллана |

## Даалгавар: Миний танилцуулга

`daalgavar/script.js` файлд:

1. Нэр, нас, хот, дуртай хоол, сурагч эсэхээ хувьсагчид хадгал.
2. Төрсөн оноо бодож гарга.
3. Өөрийгөө танилцуулсан өгүүлбэр үүсгээд консол дээр хэвлэ.
4. Өгүүлбэрээ хуудсан дээр харуул (бэлэн мөр байгаа).

## Өөрийгөө шалга

- `let` болон `const` хоёрын ялгаа юу вэ?
- `"5" + "3"` болон `5 + 3` хоёрын хариу яагаад өөр вэ? Консол дээр туршаад үз.
