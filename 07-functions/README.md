# 07. Функц

## Зорилго

- Функц зарлах, дуудах
- Параметрээр утга дамжуулах
- `return`-ээр утга буцаах
- Давтагдсан кодыг функц болгож цэгцлэх

## Функц гэж юу вэ?

Функц бол **нэртэй бөөн код**. Нэг удаа бичээд, нэрээр нь хэдэн ч удаа дуудаж болно. Хоолны жортой адил: жорыг нэг удаа бичнэ, хоолыг хүссэн үедээ хийнэ.

## Зарлах ба дуудах

```js
// Зарлах: жороо бичнэ. Энэ үед ажиллахгүй
function sayHello() {
  console.log("Сайн уу!");
}

// Дуудах: жороороо хоол хийнэ. Энэ үед ажиллана
sayHello();
sayHello();
```

## Параметр

Параметр бол функцэд гаднаас өгөх утга. Жорын "орц" гэж бодож болно.

```js
function greet(userName) {
  console.log("Сайн уу, " + userName + "!");
}

greet("Болд");    // Сайн уу, Болд!
greet("Сараа");   // Сайн уу, Сараа!
```

Нэг функц өөр өөр утгаар дуудагдаж, өөр өөр үр дүн гаргана.

## return

Функц хариугаа буцааж өгч болно:

```js
function double(number) {
  return number * 2;
}

const result = double(4);   // result = 8
```

## Давтагдсан кодыг цэгцлэх

06-р хичээлд ижил `if` хэсгийг хоёр товчинд хоёр удаа бичсэн. Функцтэй бол нэг удаа бичнэ:

```js
function updateScreen() {
  scoreText.textContent = score;

  if (score >= 10) {
    statusText.textContent = "Ялагч!";
  } else {
    statusText.textContent = "Үргэлжлүүл";
  }
}

plusButton.addEventListener("click", function () {
  score = score + 1;
  updateScreen();
});

minusButton.addEventListener("click", function () {
  score = score - 1;
  updateScreen();
});
```

Одоо текстээ өөрчлөх бол ганц газар засна.

## Чи функцийг аль хэдийн хэрэглэж байсан

`addEventListener("click", function () { ... })` доторх `function () { ... }` бол **нэргүй функц**. Түүнийг товч дарагдах үед хөтөч өөрөө дууддаг.

## Түгээмэл алдаа

| Алдаа | Засвар |
|---|---|
| Функц зарлаад дуудаагүй | Нэрийг нь хаалттай бич: `sayHello();` |
| `sayHello` гэж хаалтгүй бичих | `sayHello()` |
| `return` мартах | `return`-гүй функц `undefined` буцаана |
| `function showMood(emoji, text)` гээд ганц утга дамжуулах | Параметрийн тоо, дараалал таарах ёстой |
